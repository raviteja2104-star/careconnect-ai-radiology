# Pilot Success Criteria

The pilot deployment is deemed a success—and authorization is granted to scale to the wider hospital network—only if the following metrics are met at the conclusion of the 14-day Hypercare window.

| Category | Success Metric | Measurement Source |
| :--- | :--- | :--- |
| **System Availability** | >= 99.9% uptime during business hours. | Prometheus / Grafana |
| **Clinical Efficacy** | >= 95% of OPD encounters complete digitally (no paper). | Application Analytics |
| **Financial Integrity** | 0 payment reconciliation defects or lost webhooks. | Finance EOD Reports |
| **Reliability** | 0 SEV-1 Incidents. | Incident Reports (PIR) |
| **Security** | 0 confirmed security breaches or PHI leaks. | Security Audits |
| **Adoption** | >= 80% of pilot doctors logged in > 3 times/week. | Auth Logs |
| **User Satisfaction** | > 4.0/5.0 on End-of-Pilot CSAT Survey. | Survey Tool |
